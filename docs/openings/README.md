# Openings

Short articles. Each is one decision and what it made
possible — something that was not on the list when the
decision was taken.

These are not principles. Principles are rules; they must
not rot (except a "Spelled today" section). Openings may
grow, split, or wait on a seam that is designed but not
yet built. They never override [vision](../vision.md) or
[principles](../principles/).

When a concept is added, renamed, or changes meaning,
update [terminology](../terminology.md) in the same
change. An opening that describes work not yet built
says so.
