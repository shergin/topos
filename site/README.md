# The site

<https://shergin.github.io/topos/> — the documentation site, generated by
this crate and deployed from `master` by `.github/workflows/pages.yml`.

The repository's rule holds here: no reading on the site is typed by hand.
Every plate is a block of Rust in [`figures/`](figures/) — one block per
file, both `include!`d and `include_str!`ed, so the code shown beside a
plate is the code that ran — that records a graph and asks the crate for
one of its readings: the spec dump, the derivative, a plan, the StableHLO,
a run's values, a training curve, a notebook card. The repository's own
docs (`docs/*.md`, the changelog, the example READMEs) are the text of many
pages; the site adds plates under their headings and rewrites their links.
The site-authored chapters live in [`content/`](content/).

```sh
cargo run -p topos-site                    # writes site/dist (pages and plates)
./site/build.sh                            # the same, plus the wasm for the playground
python3 -m http.server 4173 --directory site/dist
```

A `{{directive}}` on a line of its own in any page becomes a plate:
`{{figure name}}` (the reading and its code; add `nocode` to fold the code
away), `{{code name}}`, `{{pair a b}}`, `{{gallery example_name}}`, and the
wasm-driven `{{playground}}`. A caption follows a `|`.
`SITE_CONTACT_SHEET=1 cargo run -p topos-site` also writes `dist/contact/`,
every figure on one page, for proofing.

The [gallery](../examples/) plates are the outputs of the examples, recorded
into [`gallery/`](gallery/) by [`record.sh`](record.sh) — what each example
prints into a pipe, verbatim.

The pieces the site and the playground share — the IR dump as marked-up
HTML, the graph as a layered SVG, the code highlighter — are the
[`plates`](plates/) crate. The playground's wasm is [`wasm/`](wasm/).
